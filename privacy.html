Privacy Policy

Wild Sit Down Uploader — last updated 16 September 2026

Summary

This tool runs on one person's own computer and uploads videos to that same person's own YouTube channel. It has no server, no other users, and it sends no data anywhere except to Google's own APIs in order to perform the upload.

What is accessed

When the operator signs in, the tool requests one Google OAuth scope, https://www.googleapis.com/auth/youtube.upload. This permits uploading a video to the channel that was selected at sign-in. No other Google account data is requested or accessed.

What is stored, and where

  • The OAuth token issued by Google is stored in a file on the operator's own computer, so that sign-in is not required on every run.
  • Nothing is stored on any server. There is no database, no analytics and no logging service.
  • Video files and their titles, descriptions and tags stay on the operator's computer until they are uploaded to that operator's own YouTube channel.

What is shared

Nothing is shared with any third party. Data is transmitted only to Google, and only as part of the upload request the operator initiates.

Retention and deletion

The stored token remains until the operator deletes the file or revokes access. Deleting the token file removes it immediately and permanently.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions. Revoking access invalidates the stored token.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

The tool is not directed to children and collects no information from them.

Changes

If this policy changes, the date at the top of this page is updated.
